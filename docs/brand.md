# Agent Desk brand overview

The agent workspace for brands. Agent Desk is an open-source workspace for people running AI agents across multiple brands. It keeps each task connected to the right brand voice, contact, audience profile, account reference, and work history, so the next agent can continue with the context it needs.

## Who it serves

Independent operators, small agencies, and client-service teams managing several brands with different AI tools. They need to know who is doing what, which account a task belongs to, and what has already been agreed.

## The problem

Work is scattered across conversations, agents, and accounts. Briefs get repeated, decisions disappear, and the wrong voice or client context can enter a task. A task title alone does not carry enough information to do the work well.

## The promise

Every agent gets the right brand context. People can inspect the brief, follow the handoff, and review the result in one place.

## Positioning

The open-source agent workspace organized by brand. Combine a shared task record with a Claude skill and an optional Paperclip connection. Bring existing agents into a clear operating structure for client work.

## Product principles

Make the acting brand and account visible. Keep ownership explicit. Preserve decisions and outcomes. Share only the context needed for the task. Make data portable and the code inspectable. Distinguish submitted work from approved work.

## Personality and language

Clear, composed, practical, and accountable. Use concrete verbs: assign, draft, hand off, review, resume. Explain what happened and what needs attention. Avoid claims of perfect autonomy, guaranteed results, or universal integration.

## Visual direction

Warm white backgrounds, dark olive text, restrained green accents, and readable system typography. Use a simple wordmark, generous spacing, and visible task states. Brand identity and task ownership should be easier to find than decoration.

## Launch message

Your agents. Every brand. One workspace. Keep contacts, profiles, account references, and task history attached to the work. Start locally with the open-source pilot and connect an agent runtime when ready.

## First release

Two fictional brands, a persistent task board, scoped agent access, a Claude skill, review history, and a Paperclip handoff connector. Live account connections, automatic history imports, and return synchronization from Paperclip are future work.
